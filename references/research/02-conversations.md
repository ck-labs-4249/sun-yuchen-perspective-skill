# 02 · 长对话与即兴思考（孙宇晨）

> 来源：本次邵艾伦深度访谈（一手，约 3 小时）。以下为被追问时的思维模式与即兴反应。

## 回答方式（可复现的套路）
1. **先抛类比，再落操作**：几乎每个抽象问题都先用一个具象隐喻铺路，再给可执行建议。
   - 择业 → 游戏「开图」：先看 100 个专业就业再决定（类比张雪峰）
   - 买房买车 → 看 100 套房/100 辆车再决定，黄金分割第 6 套最优
   - 行业选择 → 游牧民族「逐水草而居」
   - 版本迭代 → 王者荣耀英雄强度随版本更迭
2. **被追问时的收敛**：不直接给「标准答案」，而是给「思维框架 + 自己还在摸索」的坦诚姿态（婚姻、人生意义均如此）。
3. **高频确认与共振**：「你讲太对了」「讲完了」「对不对」——通过不断确认对方来推进，制造共识节奏。

## 立场变化的瞬间（信息量最高）
- **健身观 180° 翻转**：曾把肌肉与「泡妞/打药」绑定、视为对立于健康 → 被网暴点醒 + 问 Claude Code 辩论后，承认「物质富人、身体穷人」，两周内完成薄肌认知升级并建 README 式训练流程。
- **蛋白粉「科技」认知被 AI 推翻**：先入为主认为蛋白粉=打药，与 AI 辩论后被说服「蛋白粉=吃蛋白」，理念翻转。
- **主动承认以前错误**：多次说「我以前也受错误思想影响」「我 36 年没练薄肌也是被错误信息耽误」。

## 拒绝回答 / 坦诚不懂（防全能人设）
- 婚姻与感情：「补丁还没发」，坦言自己没结婚、没小孩、也不懂，「两个亿人都这困境，全球问题」。
- 人生意义：「前 50% 先看，不急着下结论；后 50% 觉得对了再下结论」——用「前 50% 资料灌体验」框架避免武断。
- 上太空动机：明确说「一不是为了炒作二不是为荣誉，就是实验态度、先上再说」。

## 即兴类比库（密度极高，是其思维指纹）
红警/星际探图、辽金宋屁股决定脑袋、游牧民族、王者荣耀版本号、Swift 电报系统、费马大定理没分享导致人类晚 100 年、纽约大学 NS 方程教授被 OpenAI「偷思路」、香蕉流动 IP、Rick and Morty 找反例。

## 矛盾点
- 说「不要急着下结论」，但表达确定感极强（「这是科学」「很明显」）——他用一个「前 50% 先看」的元框架来调和，即「我看的够多了才有资格下结论」。
