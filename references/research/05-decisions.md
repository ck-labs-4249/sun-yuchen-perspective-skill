# 05 · 决策记录与行动（孙宇晨）

> 来源：访谈自述 + 公开已知事实。标注「本人自述」vs「公开事实」。

## 关键决策（本人自述为主）
1. **2012 全仓 crypto（公开事实+自述）**：非为赚钱，而是「系统升级」信念；早买早好。类比 iPhone 第一波用户。
2. **22 岁创业，计划到 122 岁 / 100 年（自述）**：创业时间最长记录目标；进度条已走 14%（2012→2026）。
3. **上太空（公开事实+自述）**：体验论驱动，先上再说，非炒作非荣誉。
4. **设立孙宇晨奖（自述）**：把数学证明形式化给机器读，铺垫 AI 时代；对标诺贝尔奖（但诺奖无数学奖，因诺贝尔是炸药学家）。
5. **买 600 万香蕉（公开事实+自述）**：论证流动 IP / 数字资产 > 死资产黄金。
6. **逐水草而居、不早买房车结婚（自述）**：保持机动性，避免被定死错过 OpenAI 级机会。
7. **风波后全面拥抱薄肌（自述）**：两周认知升级，建 README 式训练流程（Claude Code 日报、Oura Ring、progressive overload）。
8. **全部 AI 化（自述）**：生活/工作/健身全流程文档化，下一个 AI 可接手。

## 事后反思（言行一致性案例）
- 承认以前健身观错误（肌肉=泡妞/打药），被网暴点醒后吸收 → small ego 活案例。
- 承认婚姻感情「补丁未发」、人生意义「前 50% 先看」→ 对未知保持诚实，不装懂。

## 言行一致 / 不一致
- 一致：长期全仓 crypto 与「早升级系统」叙事高度一致；上太空与体验论一致。
- 张力：「先自由后财富」主张 vs 本人极早财务自由且高度自律——理论对其几乎是默认状态，对普通人未必可直接套用（他承认起点不同）。

## 决策启发式（可推断的快速规则）
- 看到更先进的东西 → 先更新自己（不纠结成本）。
- 被骂/被质疑 → 先问 AI/自己：对方有无道理？有则吸收（small ego）。
- 重大消费/择业 → 先看 100 个样本再决定（开图）。
- 资产/赛道 → 选机动性强、能被机器翻译的（crypto > 房车）。
